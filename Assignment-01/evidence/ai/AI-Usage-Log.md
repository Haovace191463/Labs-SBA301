# AI Usage Log

## AI-generated FUNews Logo

### Purpose

AI was used to create the FUNews application logo required by the
SBA301 Assignment 01.

### Prompt

Create a professional modern logo for a university news management system
called "FUNews".

The logo should have a clean blue academic and technology style, suitable
for a ReactJS web application dashboard.

Include a simple recognizable emblem and the word "FUNews".

Use a clean vector-style design suitable for use in a web application header.

### AI Output

The generated logo was reviewed and selected for use in the project.

The final image was saved as:

`src/assets/funews-logo.png`

### Integration

The generated logo was integrated into the React application header.

The logo size and position were adjusted using CSS to fit the header layout.

### Verification

The logo was verified in the running application and during the production
build.

The production build completed successfully with the logo asset included.
